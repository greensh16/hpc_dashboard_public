The telemetry behind HPC Dashboard

Measure the work inside your job.

logger-rs records what your HPC job actually uses, from individual CPU cores to memory, I/O, network and GPUs. It writes files that HPC Dashboard reads directly, with no service to run on the cluster.

Get logger-rs ↓Read the documentation ↗

PBS systems supported · SLURM support in development · Linux x86-64

job.pbs
# Your existing PBS job script
module load logger-rs
source logger-rs.sh

telemetry_start
mpirun -np "$PBS_NCPUS" ./my_model
telemetry_stop

Choose your setup.

On Gadi, use the shared module. For another PBS cluster on Linux x86-64, download the release package and follow the deployment guide.

GADI USERS

Use the shared module

logger-rs is already available in the shared project directory. Add the module path, load it, then source the shell library in your job script.

module use /g/data/gb02/modules
module load logger-rs
source logger-rs.sh
