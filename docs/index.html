THE QUESTION BEHIND THE BILL

37% CPU efficiency.
Now what?

A single average cannot tell you what to change. Were some cores fully busy while others sat idle? Or was every core waiting on I/O? Those lead to very different next runs.

THE COLLECTOR BEHIND THE CHARTS

Start with logger-rs.

logger-rs records what happens inside your HPC job and writes the telemetry that HPC Dashboard displays. Built for PBS systems today, with SLURM support in development. Use the shared Gadi module or download the Linux package for your own cluster.
